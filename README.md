# PB-7381 · Почасовая тарифная сетка — прототип

Кликабельный мобильный прототип настройки расписания цен (7 дней × 24 часа) для карточки
услуги iikoWeb. Сделан на iikoDS: разметка — только классы `ds-*` и токены, вёрстка экрана —
`css/prototype.css`.

**Открыть:** https://asmirnova95.github.io/pb7381-hourly-rate/

- [Вариант 1 · список по дням](https://asmirnova95.github.io/pb7381-hourly-rate/ProtoApp-Draft/pb7381-hourly-rate/variant-1.html)
- [Вариант 2 · сетка 7×24](https://asmirnova95.github.io/pb7381-hourly-rate/ProtoApp-Draft/pb7381-hourly-rate/variant-2.html)

С телефона открывается сразу: страница нарисована в каркасе устройства — статус-бар, строка
адреса и нижняя панель браузера видны, полноэкранные страницы (настройки, «Изменить тариф»)
открываются под шапкой телефона.

## Что внутри

```
ProtoApp-Draft/pb7381-hourly-rate/   прототип (html, css, js)
Design-System/                       только те css ДС, которые нужны прототипу (замыкание @import)
index.html                           редирект на прототип
```

Шрифт Roboto подключается из Google Fonts (`Design-System/components-web/font.css`), поэтому
локальных файлов шрифтов нет.

## Состояние

Данные демонстрационные: расписание, тарифы и настройки живут в памяти страницы, перезагрузка
возвращает исходное расписание. Репозиторий — витрина для просмотра, разработка идёт в рабочей
копии дизайн-системы.
